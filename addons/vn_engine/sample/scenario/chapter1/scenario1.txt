# start
Narrator: Welcome. This is the smallest game VN Engine can run: no pictures, no music, just text and choices.

# greet
Mira: Hi, I'm Mira. Want the quick tour, or should we skip ahead?
- Give me the quick tour. -> tour
- Skip ahead. -> skip

# tour
@flag took_tour = true
Mira: A name before the colon picks the speaker. A bare "Narrator:" line shows no name at all.
@jump result

# skip
Mira: Straight to the point, I like it.
@jump result

# result
@jump_if took_tour == true -> result_tour
@jump result_plain

# result_tour
Narrator: You took the tour, so the flag "took_tour" is true now. That is what @flag and @jump_if are for.
@jump the_end

# result_plain
Narrator: You skipped ahead, so "took_tour" stayed false. Open scenario1.txt and compare the "tour" node.
@jump the_end

# the_end
Mira: That's dialogue, a choice, a flag, a jump, and an ending, all in one small file. Copy this folder to start your own game.
@end sample_end
